A bordered surface for an object the user acts on.

- Use `tone="raised"` (default) on `bg`, `tone="pine"` for a quiet feature panel and `tone="navy"` for a depth panel. Each is 1px `border`, `radius-sm`, `space-6` padding.
- `eyebrow` adds a mono label in `accent`. The consumer provides the content as children, using `heading-2`, `body` and `ink-muted` for text.
- Do not nest cards, add shadows or colour the border. Do not use cards to wrap every section; group with spacing and hairlines instead.
