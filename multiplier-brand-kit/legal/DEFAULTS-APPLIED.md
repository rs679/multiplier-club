# Defaults applied to the owner review candidates (version 0.9)

**Status: not legal advice and not yet reviewed by counsel.** Seven documents were moved from version 0.1 to version 0.9 (owner review candidate) by resolving every `[PLACEHOLDER: ...]` and `[OPTION ...]` marker in the text that users see. This file records each non-trivial choice so the owner can confirm or change it before anything is published.

Documents covered: PLT-01, PLT-02, PLT-03, ADV-01 (including Schedule 3), ADV-02, ADV-03, ADV-05. No other document in this folder was edited.

How choices were made, in order:

1. **Known fact.** Owner decisions and confirmed facts (entity, licence, addresses, 70/30 split, Override tiers, no investor fees, on-platform viewing only, no US persons, named service providers).
2. **Suggested value.** The value suggested inside the marker itself (for example "e.g. 30", "suggested 5"), or a bracketed figure already in the draft (for example `[30]`).
3. **Recommended option.** The option marked "(recommended)" or favoured by the surrounding drafting note.
4. **Fallback.** No fact, suggestion or recommendation existed. The option more protective of Multiplier, while standard and fair to the other side, was used. These need the closest look.
5. **True without the fact.** The fact is not known and could not be defaulted, so the text was written to be accurate whatever the answer is. Nothing was invented.
